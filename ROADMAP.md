# Chinese Learning OS — Roadmap

# Phase 1 — MVP

Objectif :

Faire fonctionner parfaitement :

PDF
→ connaissances
→ révisions
→ erreurs
→ progression.

Fonctionnalités :

- application ;
- base de données ;
- import PDF ;
- extraction texte ;
- analyse IA ;
- validation ;
- historique des cours ;
- vocabulaire ;
- phrases ;
- grammaire ;
- base de connaissances ;
- recherche ;
- répétition espacée ;
- rappel actif ;
- sessions quotidiennes ;
- historique des réponses ;
- erreurs ;
- progression ;
- responsive mobile.

---

# Phase 2 — MVP+

Ajouter :

- synthèse vocale chinoise ;
- exercices d'écoute ;
- microphone ;
- enregistrement ;
- speech-to-text ;
- exercices oraux ;
- évaluation IA ;
- conversation IA.

---

# Phase 3 — Intelligence adaptative

Ajouter :

- analyse des erreurs récurrentes ;
- adaptation des sessions ;
- maîtrise multidimensionnelle ;
- préparation avant cours ;
- génération avancée d'exercices ;
- recommandations personnalisées.

---

# Phase 4 — Prononciation

Ajouter progressivement :

- entraînement des tons ;
- discrimination auditive ;
- paires de tons ;
- feedback de prononciation ;
- visualisation éventuelle du contour tonal.

Ne pas construire cette partie avant que le pipeline oral standard fonctionne correctement.

---

# Phase 5 — Ingestion des vrais cours

Possibilité future :

enregistrement ou transcription des visioconférences avec consentement de la professeure.

Pipeline potentiel :

cours
↓
audio/transcription
↓
détection des nouvelles notions
↓
détection des corrections
↓
détection des erreurs utilisateur
↓
suggestions d'ajout

---

# Phase 6 — Fonctionnalités futures

Idées potentielles :

- HSK mapping ;
- chinois traditionnel ;
- écriture manuscrite ;
- application mobile native ;
- offline ;
- export ;
- statistiques avancées ;
- portail professeur.

Ne pas développer ces fonctionnalités tant que le cœur du produit n'est pas excellent.

---

# Principe

Une fonctionnalité future ne doit jamais ralentir la stabilisation du MVP.

Le MVP doit être réellement utilisable quotidiennement avant de développer les fonctionnalités avancées.
