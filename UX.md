# Chinese Learning OS — UX / UI

## Direction artistique

L'application doit être :

- calme ;
- moderne ;
- premium ;
- personnelle ;
- minimaliste ;
- agréable quotidiennement.

Elle peut évoquer un mélange entre :

- application de productivité ;
- outil éducatif moderne ;
- carnet personnel.

Éviter une esthétique enfantine.

# Mobile

La session quotidienne doit être excellente sur téléphone.

L'utilisateur doit pouvoir réviser :

- dans les transports ;
- pendant une attente ;
- pendant 5 minutes libres.

Utiliser :

- grandes zones tactiles ;
- boutons accessibles ;
- typographie lisible ;
- microphone facilement accessible.

---

# Import PDF

Créer une zone drag & drop claire.

États :

Téléchargement...

Préparation de la validation...

Terminé.

Ne jamais laisser l'utilisateur devant un spinner sans contexte.

# Progression

---

# Animations

Animations discrètes.

Pas de confettis excessifs.

Une petite animation lors de la fin d'une session est acceptable.

---

# Accessibilité

Prévoir :

- contraste suffisant ;
- navigation clavier ;
- focus visible ;
- HTML sémantique ;
- labels ;
- boutons suffisamment grands.

Ne jamais utiliser uniquement la couleur pour indiquer :

correct / incorrect.

Utiliser également :

✓
✗
texte.
